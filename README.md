# 🌐 APIs Playground

Welcome to **APIs**, a fun collection of small projects built to explore and learn how **public APIs** work!  
Each folder in this repository contains a simple, independent project that shows how to use different APIs in real-world mini-apps.

---

## 🧠 What This Repo Is About

This repo is all about **learning by doing**. It’s made for beginners who want to understand how to:
- Fetch data from APIs using **JavaScript** or **TypeScript**
- Display the results nicely using **HTML**, **CSS**, and **Tailwind CSS**
- Build small user interfaces with **React.js**
- Handle real-world things like loading, errors, and responses

Each project has its own folder and a short guide explaining how it works.

---

## 📂 How the Projects Are Organized

Each project lives in its own folder and includes:
- A main source file or app (`src/`)
- A `process.md` file (a short document explaining what the app does)
- Any setup instructions you need to run it

---

## 🧩 Example: Books API

**Books API** is a small app that:
- Uses a public books API to fetch information about books.
- Lets you search for titles or authors.
- Displays results in a simple, responsive list.
- Uses **Tailwind CSS** for clean, modern styling.

---

## 🚀 Getting Started

If you’d like to try out one of these projects locally, follow these simple steps:

### 1. Clone the repository
```
git clone https://github.com/jatulya/APIs.git
```

### 2. Pick a project and open its folder
```
cd APIs
```

### 3. Install dependencies
```
npm install
```

### 4. Run it locally
```
npm run dev
```

That’s it! Your app will start running locally, and you can open it in your browser to explore.
